# Contributors
C3S EQC content has been developed by independent evaluators over multiple tenders,
as well as voluntary contributions from third parties.
This page lists all contributors organised by data stream.

**Pros & Cons**    
Pro:
* Easy to implement while 520's notebooks are still unchanged.
* Probably the easiest for a reader to navigate, although still not on the per-notebook level.

Con:
* Implicitly puts one data stream before another (following table of contents).
